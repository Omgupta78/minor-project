# Reproducible production dependencies (Python 3.10-3.14).
#
# Install BOTH files, in this order:
#
#     pip install -r requirements.txt
#     pip install --no-deps -r requirements-nodeps.txt
#
# The second line is not optional and not a tidiness choice. face_recognition
# declares a dependency on "dlib", and the official dlib on PyPI ships a source
# tarball and no wheels for any platform. Letting pip resolve it therefore makes
# every install compile dlib from C++ -- which needs CMake and, on Windows,
# Visual Studio Build Tools, and usually just fails.
#
# dlib-bin below is the same library as a pre-built wheel (Windows, macOS arm64
# and Linux, Python 3.10-3.14) and provides the identical "dlib" module.
# Installing face_recognition with --no-deps lets it use that instead of
# dragging the source-only package in behind it. Nothing then needs a compiler.
